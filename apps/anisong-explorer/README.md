# AniSong Explorer

Веб-таблица музыкального каталога AniSongDB: массовый поиск по спискам аниме, фильтрация по сезону, типам, названию и артисту; экспорт CSV, JSON и показателей.

Исходный проект разработчика базы: https://github.com/xSardine/AMQ-Artists-DB

## Файлы
- `site/` — статическая веб-страница и SQLite
- `scripts/build_catalog.py` — сборка полной SQLite из публичного API или образца разработчика
- `../../.github/workflows/anisong-explorer-pages.yml` — еженедельное обновление и развёртывание Pages

Сайт в этом репозитории размещён изолированно от основной системы мониторинга ЕАИС.
Если GitHub Pages настроен на GitHub Actions, рабочий адрес: https://arst113.github.io/movie_pars/

## Данные
Первоначальный SQLite-файл содержит тестовые записи и предназначен исключительно для демонстрации.
Workflow заменяет его результатом загрузки актуальной базы. При недоступности
https://anisongdb.com/api/catalog_dump использует авторский SQLite-образец.
